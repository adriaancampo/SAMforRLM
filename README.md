# SAM grain-segmentation and stereological analysis pipeline

This repository contains the complete Python → MATLAB analysis pipeline used to generate the processed segmentation data, publication figures, publication tables, and image-level statistics reported in *Zero-shot mineral segmentation in reflected-light microscopy using the Segment Anything Model* (Adriaan Campo and Eric Pirard, submitted to *Image Analysis and Stereology*, 2026).

All figures, tables, and statistical analyses reported in the publication can therefore be reproduced by running this pipeline.

## One project root

Choose one directory as the **project root**. The Python master script and MATLAB analysis use the same root.

Expected inputs:

```text
PROJECT_ROOT/
├─ Data/
│  ├─ Cu_v1/Cu_v1/...
│  ├─ FeM_v1/FeM_v1/...
│  └─ BE1109.386.10/...
└─ Checkpoints/
   ├─ sam_vit_b_01ec64.pth
   ├─ sam_vit_l_0b3195.pth
   └─ sam_vit_h_4b8939.pth
```

The SAM checkpoint files are not stored in this repository because of their size. Place the official Segment Anything checkpoints in `Checkpoints/` using the filenames shown above.

The checkpoints can be downloaded here:

ViT-B:  
https://dl.fbaipublicfiles.com/segment_anything/sam_vit_b_01ec64.pth

ViT-L:  
https://dl.fbaipublicfiles.com/segment_anything/sam_vit_l_0b3195.pth

ViT-H:  
https://dl.fbaipublicfiles.com/segment_anything/sam_vit_h_4b8939.pth

## Data for analysis

The repository contains the dataset used for Case Study II (`BE1109.386.10.zip`). Extract this archive into the `Data` folder.

The datasets used for Case Study I have previously been published by Gomes et al. References and links to the datasets are provided below:

**Cu dataset:**  
Gomes OFM, Paciornik S, Filippo MP, da Costa GAOP, Mota GLA (2021a). *Cu dataset – A copper ore labeled images dataset for segmentation training and testing*. Zenodo. doi:10.5281/zenodo.5020566.

**FeM dataset:**  
Gomes OFM, Paciornik S, Filippo MP, da Costa GAOP, Mota GLA (2021b). *FeM dataset – An iron ore labeled images dataset for segmentation training and testing*. Zenodo. doi:10.5281/zenodo.5014700.

Download and extract these datasets into the `Data` folder following the directory structure shown above.

## Installation

Create a Python environment and install the required dependencies:

```bash
python -m venv .venv
```

On Windows:

```bash
.venv\Scripts\activate
pip install -r requirements.txt
```

A MATLAB installation with the Image Processing Toolbox and Statistics and Machine Learning Toolbox is required for the publication analysis.

## Run the full pipeline

```bash
python master.py --project-root "C:\path\to\PROJECT_ROOT"
```

The Python master script:

1. preprocesses the multichannel stereological images into 256 × 256 tiles;
2. preprocesses the Cu and FeM RGB/reference datasets into 640 × 640 tiles;
3. runs SAM ViT-B, ViT-L, and ViT-H for the RGB benchmark;
4. runs SAM ViT-B, ViT-L, and ViT-H using the projection and PCA preprocessing strategies;
5. writes all MATLAB input data to `Processed_Data/`;
6. launches `matlab/MasterAnalysis.m` using the same project root;
7. generates the publication figures, tables, and statistical outputs.

To reuse an existing Python preprocessing/inference run:

```bash
python master.py --project-root "C:\path\to\PROJECT_ROOT" --skip-preprocessing --skip-inference
```

To generate the Python outputs without launching MATLAB:

```bash
python master.py --project-root "C:\path\to\PROJECT_ROOT" --skip-matlab
```

## Python ↔ MATLAB data contract

The filenames generated by `src/sam_pipeline.py` intentionally match those consumed by `matlab/MasterAnalysis.m`.

For example:

```text
Processed_Data/
└─ sam_outputs/
   └─ inference_pca_vit_l/
      └─ XY_a/
         └─ stacks/
            ├─ XY_a_tile0001_stack_pca_vit_l_labels.mat
            ├─ XY_a_tile0001_stack_pca_vit_l_mask_stack.mat
            ├─ XY_a_tile0001_stack_pca_vit_l_rgb.png
            └─ XY_a_tile0001_stack_pca_vit_l_contours.png
```

RGB benchmark outputs follow the same convention under `Cu_001/rgb_tiles/` and `FeM_001/rgb_tiles/`.

Timing CSV files for the RGB benchmark contain explicit `Dataset` and `time_seconds` columns. MATLAB therefore does not infer dataset identity from row order.

## Reproducibility notes

- MATLAB treats ellipse orientation as axial data: `phi` and `phi + pi` are equivalent.
- `La` is defined as the major intercept axis and `Lb` as the minor intercept axis.
- Publication figures are written as `Figure_1.png` through `Figure_10.png`.
- Publication tables are written as `Table_1.xlsx` through `Table_3.xlsx`.
- No user-specific absolute paths are embedded in the Python or MATLAB code.
